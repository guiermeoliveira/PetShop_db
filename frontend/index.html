Sobre o Sistema de Modelagem

Normalização de Dados
Etapa Descrição
1ª Forma Normal (1NF) Elimina grupos repetitivos e garante que cada campo contenha apenas valores atômicos.
2ª Forma Normal (2NF) Remove dependências parciais, garantindo que todos os atributos dependam da chave primária inteira.
3ª Forma Normal (3NF) Elimina dependências transitivas, assegurando que os atributos não-chave dependam apenas da chave primária.
4ª Forma Normal (4NF) Elimina dependências multivaloradas, garantindo que os atributos não-chave não dependam de conjuntos de valores.
